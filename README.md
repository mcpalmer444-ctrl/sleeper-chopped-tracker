# Sleeper Chopped Tracker Deluxe

Polished live dashboard for Sleeper league 1405228769190465536.

Features:
- Two-week additive scoring, starting Week 2
- One elimination per completed two-week round
- Live chopping-block spotlight
- Responsive/mobile layout
- Team avatars
- Standings and round history tabs
- Auto refresh every 15 seconds
- Server-side Sleeper API proxy

Run with Node 18+:
npm install
npm start

Set SLEEPER_LEAGUE_ID to change leagues.
